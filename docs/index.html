Price Watch

Log in met een GitHub-toegangstoken voor je price-watch-repository. Dat hoeft maar één keer per apparaat.

Hoe maak ik een token aan?
  1. Open GitHub → Fine-grained token aanmaken.
  2. Naam: Price Watch, vervaldatum naar keuze (bijv. 1 jaar).
  3. Repository access: Only select repositories → kies je price-watch-repo.
  4. Permissions → Repository, zet op Read and write: Actions, Contents, Secrets, Workflows.
  5. Klik Generate token en plak het hierboven.

Het token blijft alleen in deze browser bewaard en geeft uitsluitend toegang tot die ene repository.

Voor je partner: maak op dezelfde manier een tweede token aan (bijv. naam Price Watch – Sanne) en geef dat aan je partner. Zo kun je het later los intrekken.

Wie ben jij?

Kies je profiel. Je ziet dan je eigen producten en krijgt alleen meldingen over wat jij volgt. Dit apparaat onthoudt je keuze.
